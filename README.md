# ספר החוקים של מדינת ישראל, כמאגר git

החוקים שסטטוסם תקף או טרם נכנס לתוקף, קובץ Markdown לכל חוק בתיקייה `laws/`, והצעות החוק של הכנסת ה־26 כבקשות משיכה (pull requests).
המאגר נבנה אוטומטית. תוכן החוקים והצעות החוק מגיע רק מהרשומות הרשמיות של הכנסת ומספר החוקים הפתוח,
בלי ניסוח, עריכה או סיכום בידי אדם או מודל.

## מה יש כאן

| בכנסת | במאגר |
| ---: | ---: |
| חוק תקף או שטרם נכנס לתוקף | <code dir="ltr">laws/&lt;מספר החוק&gt;-&lt;שם&gt;.md</code>: הנוסח מספר החוקים הפתוח, ובכותרת הקובץ הנתונים הרשמיים והתיקונים |
| יום 0 (2026-11-23) | הקומיט הראשון ב־<code dir="ltr">main</code>: החוקים שסטטוסם תקף או טרם נכנס לתוקף באותו יום |
| הצעת חוק | ענף <code dir="ltr">bill/&lt;מספר ההצעה&gt;</code> ובקשת משיכה; טיוטה עד הקריאה הטרומית (הצעה פרטית) או הקריאה הראשונה |
| יוזמי ההצעה | מחבר הקומיט הוא היוזם הראשון, ושאר היוזמים בשורות <code dir="ltr">Co-authored-by</code> |
| דיון בוועדה | סקירה (review) עם הקישור לרשומת הישיבה ולפרוטוקול |
| הצבעה במליאה | סטטוס על הקומיט: הקריאה, מספר ההצבעה והתוצאה, עם קישור לרשומת ההצבעה |
| קבלה בקריאה שלישית | מיזוג ל־<code dir="ltr">main</code> עם השינוי בנוסח החוק, בתאריך ההצבעה |
| הצעה שנעצרה, מוזגה או הוסבה | הערה עם הסטטוס הרשמי, ובקשת המשיכה נסגרת |
| פרסום ברשומות | תג <code dir="ltr">published/&lt;מספר ההצעה&gt;</code> |

## חשוב לדעת

- זה אינו הנוסח הרשמי. הנוסח המחייב הוא זה שפורסם ברשומות; כל קובץ מקשר לפרסומים.
- בדיקת עדכניות הנוסח היא בדיקת אסמכתאות ותאריכים בלבד; היא אינה מאשרת שהטקסט המשולב כולל את כל התיקונים.
- התיקונים מוחלים על הנוסח אוטומטית מתוך נוסח ה־Word של החוק המתקן. הוראה שלא פוענחה בוודאות אינה מוחלת:
  קובץ ההצעה ב־`bills/` מסמן `manual_apply: needed` ומפרט אותה.
- חברי הכנסת מופיעים כמחברי קומיטים רק כהעתקה של הרשומה הרשמית. הכתובות שלהם הן תחת הדומיין השמור `.invalid`,
  אינן שייכות לאיש ואינן חתומות.
- בקשות המשיכה, הסקירות והסטטוסים נוצרים כשהמאגר מתעדכן, בדרך כלל יום אחרי הרשומה הרשמית; תאריכי הקומיטים
  הם תאריכי הרשומה.
